# 🎨 Sponsor Carousel Widget

Widget do płynnego wyświetlania logo sponsorów z efektem fade (alpha blending) dla M5Stack CoreS3 + LVGL.

## 🚀 Quick Start (5 minut)

### 1️⃣ Konwertuj loga (jednorazowo)
```bash
cd tools
./convert.sh
```

To zainstaluje Pillow i przekonwertuje PNG → LVGL C arrays.

**Uwaga (Python 3.13+):** Jeśli pojawi się błąd "externally-managed-environment":
```bash
python3 -m pip install --break-system-packages pillow
```

### 2️⃣ Dodaj do kodu

**W `src/main.cpp`:**
```cpp
#include "pages/SponsorsPage.h"

void setup() {
    // ... existing code ...
    
    lv_obj_t *sponsorsScreen = SponsorsPage::create();
    navigator.registerScreen(SPONSORS, sponsorsScreen);
    navigator.showPage(SPONSORS);  // Pokaż na start
}
```

### 3️⃣ Upload
```bash
pio run --target upload
```

**Gotowe!** Logo będą się wyświetlać z płynnym fade przez 4s każde, w losowej kolejności.

## 📖 Jak to działa?

```
┌─────────────────────────────────────────────────┐
│  SponsorCarousel Widget (lib/widgets/)          │
│  ┌───────────────────────────────────────────┐  │
│  │  img_current  ░░░░░ (fade out)            │  │
│  │  img_next     █████ (fade in)             │  │
│  └───────────────────────────────────────────┘  │
│                                                  │
│  Timer (4000ms) → show_next_logo()              │
│    ↓                                             │
│  1. Wybierz losowe logo (lub kolejne)           │
│  2. Animacja fade: 500ms crossfade              │
│  3. Zamień img_current ↔ img_next               │
└─────────────────────────────────────────────────┘
```

### Architektura
- **Zero dziedziczenia** - tylko statyczne metody (KISS)
- **LVGL native** - bezpośrednie API calls
- **Double buffering** - 2 obiekty `lv_image` dla smooth crossfade
- **Standalone** - nie wymaga PageManager lifecycle

## 🎛️ Customizacja

### Zmień timing
```cpp
// W SponsorsPage.cpp:
SponsorCarousel::start(5000, true);  // 5s zamiast 4s
```

### Kolejność sekwencyjna (nie losowa)
```cpp
SponsorCarousel::start(4000, false);  // false = po kolei
```

### Zatrzymaj ręcznie
```cpp
if (user_wants_skip) {
    SponsorCarousel::stop();
    navigator.showPage(NEXT_PAGE);
}
```

### Dodaj nowe logo

1. Dodaj PNG do `img/`
2. Edytuj `tools/convert_logos.py`:
   ```python
   logos = {
       # ... existing ...
       "new_logo.png": "logo_new",
   }
   ```
3. Konwertuj: `./tools/convert.sh`
4. Dodaj w `SponsorsPage.cpp`:
   ```cpp
   SponsorCarousel::addLogo(&logo_new);
   ```

## 🔧 API Reference

### `SponsorCarousel::init(parent, x, y, width, height)`
Inicjalizuje widget na ekranie.
- **parent**: `lv_obj_t*` (ekran)
- **x, y**: pozycja (px)
- **width, height**: rozmiar obszaru (logo auto-scale)

### `SponsorCarousel::addLogo(img_desc)`
Dodaje logo do karuzeli.
- **img_desc**: `const lv_image_dsc_t*` z `sponsor_logos.h`

### `SponsorCarousel::start(duration_ms, random)`
Uruchamia animację.
- **duration_ms**: czas wyświetlania (default: 3000)
- **random**: losowa kolejność (default: false)

### `SponsorCarousel::stop()`
Zatrzymuje i chowa loga.

### `SponsorCarousel::cleanup()`
Zwalnia pamięć LVGL.

## 📊 Wydajność

| Parametr | Wartość |
|----------|---------|
| **Logo size** | ~280x140 px |
| **Format** | RGB565 (2 bytes/px) |
| **RAM per logo** | ~78 KB Flash |
| **Total (6 logos)** | ~470 KB Flash |
| **CPU during fade** | ~2-5% |
| **FPS** | 60 fps |

### Optymalizacja
Jeśli brakuje Flash, zmniejsz rozmiar w `tools/convert_logos.py`:
```python
png_to_lvgl_c(path, name, max_width=200, max_height=100)
```

## 🐛 Troubleshooting

### "No logos added!" w Serial Monitor
```bash
# Sprawdź czy .c jest kompilowany:
cat platformio.ini | grep "build_src_filter"
# Powinno być: +<../include/*.c>
```

### Logo nie widać
```cpp
// Sprawdź pozycję - czy mieści się w ekranie 320x240?
SponsorCarousel::init(screen, 10, 60, 300, 150);
//                             ^x  ^y  ^w   ^h
```

### Out of memory
```bash
# Zmniejsz rozdzielczość logo:
# W tools/convert_logos.py zmień:
max_width=200, max_height=100  # było 280x140
```

### Flickering / migotanie
```cpp
// W SponsorCarousel.cpp zwiększ fade_duration:
const uint32_t fade_duration = 800;  // było 500ms
```

## 📝 Przykłady Integracji

### Pokazuj na początku i końcu koncertu
```cpp
void setup() {
    navigator.showPage(SPONSORS);  // Start z logo
}

void loop() {
    // MQTT event handling
    if (event.type == "CONCERT_END") {
        navigator.showPage(SPONSORS);  // Wróć do logo
    }
}
```

### Skip po 20 sekundach
```cpp
void loop() {
    static unsigned long sponsors_start = 0;
    
    if (navigator.getCurrentPage() == SPONSORS) {
        if (sponsors_start == 0) sponsors_start = millis();
        
        if (millis() - sponsors_start > 20000) {
            navigator.showPage(BEFORE_CONCERT);
            sponsors_start = 0;
        }
    }
}
```

### Manual skip przyciskiem
```cpp
if (hmi.getButtonB() && navigator.getCurrentPage() == SPONSORS) {
    navigator.showPage(BEFORE_CONCERT);
}
```
